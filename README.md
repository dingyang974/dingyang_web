# 丁杨 AI产品经理作品集

这是一个基于 Vite、React、TypeScript 的单页作品集网站，用于展示 AI 产品经理求职定位、核心优势、重点项目、实习经历和技能标签。

## 本地运行

```powershell
npm install
npm run dev
```

## 生产构建

```powershell
npm run build
```

构建产物会生成在 `dist/`，可部署到 Vercel、Netlify 或其他静态网站托管服务。

## 内容修改

主要文案集中在 `src/content/profile.ts`。后续优化项目包装时，优先修改这个文件。
